### Ideas que evolucionan

**Aluvo** reúne nuestros proyectos de software, inteligencia artificial y automatización. Este es el punto de encuentro para desarrollar, documentar y mejorar lo que construimos.

### Nuestro enfoque

| Área | Propósito |
| --- | --- |
| **Software** | Crear soluciones claras, útiles y fáciles de mantener. |
| **Inteligencia artificial** | Explorar aplicaciones de IA con objetivos concretos y resultados verificables. |
| **Automatización** | Simplificar tareas repetitivas y conectar procesos. |

### Cómo colaboramos

- **Claridad desde el inicio.** Cada proyecto debe explicar su propósito, alcance y puesta en marcha.
- **Cambios con contexto.** Usamos issues y pull requests para documentar propuestas y revisar el trabajo.
- **Mejora continua.** Compartimos aprendizajes y mantenemos la documentación junto al código.

### Explora nuestros proyectos

Los repositorios de esta organización reúnen el trabajo de Aluvo. Revisa el README de cada proyecto para conocer su estado, sus instrucciones y las formas de participar.
